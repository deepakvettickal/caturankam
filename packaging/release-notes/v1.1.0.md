**Caturankam 1.1** lets you watch the best game on Lichess right now, and has a new icon.

## What's new

- **Watch live.** Press **W**, or **Watch** in the sidebar, to follow the game on Lichess
  TV: both players with their titles (GM, IM…), ratings and clocks, and every move on the
  board. When the game ends, the next one starts on its own. No login needed. **W** again
  stops.
- **Material lead.** `+4` beside the player who is ahead, in your games and on TV.
- **A new icon:** a solid black rook over a pencil construction sketch on graph paper. It
  now shows in the Dock too (1.0 showed egui's logo there).
- **Smoother install.** Installed with Homebrew, the app now opens without the macOS
  security warning. Releases are also signed with a stable certificate, so macOS stops
  asking for Keychain access after every update. You'll be asked one last time when
  moving from 1.0.
- **Menus match the sidebar:** ⌘S sidebar, ⌘T light/dark, ⌘R randomize, ⌘F flip.
- **Smoother randomizing:** no loading circle over the board when the pieces or board
  change.

## Install

With Homebrew (recommended, no security warning):

```sh
brew tap deepakvettickal/caturankam https://github.com/deepakvettickal/caturankam
brew install --cask caturankam
```

Already installed with Homebrew? `brew upgrade --cask caturankam`.

Or download `Caturankam-1.1.0.dmg` below, open it, and drag **Caturankam** to
**Applications**. This release isn't notarized by Apple, so macOS blocks it the first
time; run this once to allow it:

```sh
xattr -dr com.apple.quarantine /Applications/Caturankam.app
```

or click **Open Anyway** in **System Settings ▸ Privacy & Security** after the first
try. Runs on macOS 11 or later, on Apple Silicon and Intel.

If the Dock still shows the old icon, it's macOS's icon cache: `killall Dock` refreshes
it.

To check the download: `shasum -a 256 Caturankam-1.1.0.dmg` should match
`checksums.txt`.

Caturankam is an independent project, not an official Lichess app.
